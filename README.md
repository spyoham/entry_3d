- **엔트리 3D 물리 시뮬레이터** (최신 `엔트리 3D 물리 시뮬레이터 v1.0`): 젤리 같은 탄성체와 강체의 3D 시뮬레이션. 탄성체는 사면체 유한요소(Stable Neo-Hookean) + Verlet, 강체는 6자유도(각운동량 보존, 방향 RK4) + 충격량 접촉. 정확 모드와 빠른 모드(단단한 물체는 θ법 + 공회전 유한요소)를 도중에 바꿈. 젤리끼리(공간 해시)·젤리와 강체·강체끼리 충돌, 마우스로 젤리를 잡아당기는 잡기. 장면: 젤리 큐브 낙하, 젤리 계단, 젤리 더미, 젤리 탑과 쇠공, 쇠공과 젤리 판, 젤리 놀이터, 외팔보(보 이론과 비교). 순정 엔트리에서 한 장(1/30초)에 수 초, tessvm에서 수십 배 빠름. 설명서는 `엔트리 3D 물리 시뮬레이터 v1.0 설명서.md`
- **엔트리 다양체 이징** (최신 `엔트리 다양체 이징 v1.0`): 이징 e(t)를 n차원 다양체 위로 옮긴 작품. 두 점 사이를 측지선을 따라 `γ(t) = Exp_A(e(t)·Log_A B)`로 가고, 넘치는 이징은 측지선 위에서 넘친다. 다양체 ℝⁿ·Sⁿ(입체 사영)·Hⁿ(푸앵카레 공)·Tⁿ·SO(3)(쿼터니언)·ℝ₊와 곱 다양체, 축마다 다른 벡터 이징, 측지선 de Casteljau로 만드는 다양체 베지어, 이징 15가지와 손잡이로 만드는 cubic-bezier. 직접 만든 7축 가변 획 글꼴(굵기·너비·기울기·각짐·대비·펜촉 각도·색, 켠 축들이 M)과 지구 위를 나는 종이비행기(S² × SO(3) × ℝ₊ × S¹, 방향은 평행 이동)에 적용하고, 축·위경도·오일러각을 그냥 보간한 것과 나란히 비교. 예시 10개(자동 재생, 그대로 조작 가능)와 폰트·3D 실험실(슬라이더, 축 켜고 끄기, 키 끌어 돌리기·옮기기). 순정 엔트리와 tessvm(60프레임/초). 설명서는 `엔트리 다양체 이징 v1.0 설명서.md`, 썸네일 `엔트리 다양체 이징 썸네일.png`
