# entry_3d

엔트리(Entry)에서 블록만으로 만든 3D 엔진과 게임 모음입니다.

## 작품
- **3D 엔진** (`3D v1` ~ `3D v5`): 범용 3D 엔진. 사용법은 `3D v5 사용설명서.md`
- **F1 Online 3D** (최신 `F1 Online 3D v3.3.1`; 이전 이름 `3D 레이싱` `v1` ~ `v12`, `v2.6`, `v3.0`, `v3.1`, `v3.2`, `v3.3`, `v4.0`, `v4.1`, `v4.2`, `v4.3`, `v5.0`, `v5.1`, `v5.2`, `v6.0`, `v6.1`, `v6.2`, `v6.3`): F1 서킷 19개. 아케이드/리얼리스틱 규칙(타이어·피트·날씨·데미지·예선·깃발·세이프티카·ERS), AI 성격, 리플레이·TV 카메라, 트랙 공유 코드, 엔진 사운드(v7). 레벨·도전과제·튜닝, 연습 모드, 서킷별 기록과 고스트, 실시간 변수 랭킹·저장, 주변 차 소리(v8). 카테고리 메뉴와 동시 저장 보강(v9). 백업 코드(v11), 벽 접촉 완화(v12). 경사에 따라 기우는 차체와 바퀴별 온도·마모·타이어 점검(v2.6). Q1–Q3, 포메이션 랩, 연료·브레이크 온도·락업·플랫스팟, 트랙 고무·온도, 구역별 비와 드라이 라인, VSC·블루 플래그, 고장, AI 언더컷, 팀별 성격, 7가지 세팅(v3.0). 벽에 끼인 AI 복구(v3.1). 코드 불러오기 뒤 키 오작동 수정(v3.2). 온라인 저장 용량 줄이기(v3.3). 8개 서킷을 실제 지도·지형으로(모양·길이·고저, 실제 건물·숲·물·랜드마크, 먼 산; v4.0). 가까이 지나는 다른 구간 표시·트랙 침범 건물 수정(v4.1). 다리·제방, 실제 지형(HIGH 교차로, ULTRA 전체), 다른 구간을 덮던 잔디 수정(v4.2). 건물이 벽을 덮던 그리기 순서 수정(v4.3). 실제 서킷 6개 추가: 바레인·멜버른·몬트리올·레드불 링·잔드보르트·오스틴(v5.0). 연산 정수화로 tessvm 약 4% 가속(v5.1). 물리·AI 계산 정수화로 tessvm 최대 6% 가속(v5.2). 실제 서킷 5개 추가(이몰라·헝가로링·바르셀로나·제다·라스베이거스, 19곳), 피트 휠건 미니게임, 사진 모드, 그래픽 AUTO(v6.0). 로딩 화면과 그리기 계산 정수화·전처리로 느린 PC에서 7~10% 가속(v6.1). 헤어핀 잔디 띠가 도로를 덮던 버그와 건물·도로·땅 그리기 순서 수정(v6.2). AI 사고·고장이 너무 잦던 버그(엔트리 무작위 수 반올림), 헤어핀 도로 이탈 오판정, 내리막 점프, 앞차·옆 차를 보는 AI(v6.3). 이름을 F1 Online 3D로 바꾸고 온라인 저장·랭킹을 Entry Sync 확장의 `?!` 리스트로(2.0.0). 온라인 대전(방 만들기·입장), 관전, 채팅(2.1.0). 올리기 크기 초과 수정(2.1.1). 온라인 끊김·작품 정지 처리와 복귀(2.1.2). 개인·세계 최고기록이 안 바뀌던 버그(2.1.3). 온라인 방 차 규칙: 업그레이드 켜기, 모두 같은 차(2.2.0). 오늘의 도전: 날마다 바뀌는 서킷·차·조건과 그날의 랭킹, 연속 보상(2.3.0). 온라인 빠른 채팅, 숫자 키 3~9(2.4.0). 커리어 모드: 8개 팀, 6라운드 시즌, 팀 목표·라이벌·평판·계약(3.0.0). 후진 조향이 좌우 바뀌던 버그(3.0.1). 경주 전체 리플레이와 자동 하이라이트(3.1.0). 손상 확장: 서스펜션·펑크·엔진(3.2.0). 세이프티카 로드카 모델(3.3.0). 타임 트라이얼에서 고스트가 가까울 때 심해지던 랙(3.3.1). 처음이라면 `3D 레이싱 소개.md`(사용법과 사용된 기술), 최신 변경은 `F1 Online 3D v3.3.1 설명서.md`, 썸네일은 `3D 레이싱 썸네일.png`(이전 설명서는 `old/`)

- **엔트리 레이트레이서** (최신 `엔트리 레이트레이서 v1.3.1`): tessvm에서 도는 실시간 레이트레이서. 체커 바닥·그림자·반사, 움직이는 크롬 공, BVH로 찾는 삼각형 물체 넷(계단식 피라미드, 체스 나이트, 인셉션의 팽이, 광나는 스포츠카 — CC0 모델, `엔트리 레이트레이서 LICENSES.txt`). 줄 단위로 구간을 식으로 풀어 닿을 수 있는 물체만 검사. 이 PC에서 480×270(인터레이스) 60틱/초. 설명서는 `엔트리 레이트레이서 v1.3.1 설명서.md`. `v1.alpha`는 "~인 동안 반복하기"와 딜레이 제거 코드 없이 재귀만으로 도는 실험판
- **엔트리 GMP** (최신 `엔트리 GMP v1.0`): GNU MP처럼 큰 수를 다루는 mpz(정수)·mpq(분수)·mpf(부동소수) 함수를 GMP와 같은 이름으로. 10^7진법, 파라미터 타일 곱셈·Karatsuba·Barrett·Newton, GMP와 같은 BPSW 소수 판정. 데모: 원주율(Chudnovsky 이진 분할), 밀러-라빈 소수 판정, 다음 소수, 큰 수 계산기. 설명서는 `엔트리 GMP v1.0 설명서.md`
- **엔트리 복소함수 그래퍼** (최신 `엔트리 복소함수 그래퍼 v2.1.1`): 식을 글자로 넣으면 복소함수를 정의역 색칠로 그리고, z가 없는 식은 값을 계산. 식을 벡터 연산 프로그램으로 컴파일(상수 접기, 정수 거듭제곱), 16→1픽셀 점진 렌더링, 펜 복제본 띠. 순정 엔트리에서 돌고 tessvm에서 약 40배 빠름. 감마·제타 함수, 클릭으로 영점·극 찾기(뉴턴법 + 편각 바퀴 수), 매개변수 a와 시간 t(v1.1). 반복 `iter`·`esc`(망델브로·줄리아 집합), 격자가 옮겨진 모습(v1.2). |f|를 높이로 한 3D 곡면과 리만 구, 끌어서 돌리기(v2.0). 화면 단추와 식 입력판으로 키보드 없이 조작(v2.1). 단추를 누르면 입력창이 뜨던 버그(v2.1.1). 설명서는 `엔트리 복소함수 그래퍼 v2.1.1 설명서.md`
- **엔트리 exp 함수** (최신 `엔트리 exp 함수 v1.1`, `.eo`와 `.ent`): 엔트리에 없는 e^x를 값 함수로. `exp`는 탄젠트 한 번과 제곱 13번, 뉴턴법 한 번으로 커뮤니티의 "exp 종결"보다 약 1.9배 빠르고(함수 몸통 39 → 21 µs), `exp 정밀`은 어디서나 3 ulp 이하. 둘 다 리스트 없음. 4096칸 표를 읽는 `exp 표`(v1.1)는 18 µs에 어디서나 5 ulp 이하. 설명은 `엔트리 exp 함수 v1.1 설명서.md`
- **엔트리 OBJ 렌더러** (최신 `엔트리 OBJ 렌더러 v1.0`): OBJ 파일(3D 모델)의 글자를 붙여넣으면 블록으로 읽어 그리는 뷰어. 순정 엔트리와 tessvm 모두. 줄바꿈이 사라진 글을 낱말 단위로 읽고(`a/b/c`, 음수 번호, 다각형, `.mtl` 색), 리스트 5000칸 한도 안에서 5000개씩 16쪽으로 나눠 면 8만 개까지 담음. 같은 자리 꼭짓점 합치기, 닫힌 겉면이면 앞면만, 사각형 면 그대로, 정렬 없는 깊이 사슬, 움직일 때 쓰는 성긴 모델 둘, 순정에서는 옛 사칙연산 블록과 펜 테두리로 실선 없애기. tessvm에서 면 7,560개가 60틱/초. 큰 모델은 `엔트리 OBJ 렌더러 모델 넣기.html`로 모델이 든 작품 파일을 만듦. 설명서는 `엔트리 OBJ 렌더러 v1.0 설명서.md`
- **엔트리 배틀로얄 3D** (최신 `엔트리 배틀로얄 3D v1.0`): tessvm에서 도는 1인칭 배틀로얄. 플레이어 1명 + AI 29명(PVE), 2 km 섬(건물 약 250채·소품 약 2400개, 도시·군사기지·항구·마을·농장), 비행기 낙하·낙하산, 파밍(실총 15종·실제 부착물 15종·방어구·회복템·투척물), 7단계 자기장. AI는 시야·가림·감지 계기·청각으로 찾고, 반응 시간·추적하며 줄어드는 조준 오차·리드·반동·점사·좌우 무빙·엄폐와 피킹·수류탄으로 싸우며, 멀리서는 내비 그래프 위 요약 시뮬로 실제 파밍과 교전을 한다. 오브젝트 2개(붓으로 3D·총·HUD 전부, 글자 복제본), 셀 순서 + 빌드 때 만든 BSP로 정렬 없는 화가 알고리즘, 지연 꼭짓점 변환·LOD. 1/4 CPU에서 20 fps 이상이 목표. 설명서는 `엔트리 배틀로얄 3D v1.0 설명서.md`
