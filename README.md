## 작품
- **3D 엔진** (`3D v1` ~ `3D v5`): 범용 3D 엔진. 사용법은 `3D v5 사용설명서.md`
- **3D 레이싱** (`3D 레이싱 v1` ~ `v12`, `v2.6`, `v3.0`, `v3.1`, `v3.2`, `v3.3`, 최신 `v4.0`): F1 서킷 8개. 아케이드/리얼리스틱 규칙(타이어·피트·날씨·데미지·예선·깃발·세이프티카·ERS), AI 성격, 리플레이·TV 카메라, 트랙 공유 코드, 엔진 사운드(v7). 레벨·도전과제·튜닝, 연습 모드, 서킷별 기록과 고스트, 실시간 변수 랭킹·저장, 주변 차 소리(v8). 카테고리 메뉴와 동시 저장 보강(v9). 백업 코드(v11), 벽 접촉 완화(v12). 경사에 따라 기우는 차체와 바퀴별 온도·마모·타이어 점검(v2.6). Q1–Q3, 포메이션 랩, 연료·브레이크 온도·락업·플랫스팟, 트랙 고무·온도, 구역별 비와 드라이 라인, VSC·블루 플래그, 고장, AI 언더컷, 팀별 성격, 7가지 세팅(v3.0). 벽에 끼인 AI 복구(v3.1). 코드 불러오기 뒤 키 오작동 수정(v3.2). 온라인 저장 용량 줄이기(v3.3). 8개 서킷을 실제 지도·지형으로(모양·길이·고저, 실제 건물·숲·물·랜드마크, 먼 산; v4.0). 처음이라면 `3D 레이싱 소개.md`(사용법과 사용된 기술), 최신 변경은 `3D 레이싱 v4.0 설명서.md`(이전 설명서는 `old/`)
