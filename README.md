# entry_3d

엔트리(Entry)에서 블록만으로 만든 3D 엔진과 게임 모음입니다.

## 작품
- **3D 엔진** (`3D v1` ~ `3D v5`): 범용 3D 엔진. 사용법은 `3D v5 사용설명서.md`
- **F1 Online 3D** (최신 `F1 Online 3D v3.3.0`; 이전 이름 `3D 레이싱` `v1` ~ `v12`, `v2.6`, `v3.0`, `v3.1`, `v3.2`, `v3.3`, `v4.0`, `v4.1`, `v4.2`, `v4.3`, `v5.0`, `v5.1`, `v5.2`, `v6.0`, `v6.1`, `v6.2`, `v6.3`): F1 서킷 19개. 아케이드/리얼리스틱 규칙(타이어·피트·날씨·데미지·예선·깃발·세이프티카·ERS), AI 성격, 리플레이·TV 카메라, 트랙 공유 코드, 엔진 사운드(v7). 레벨·도전과제·튜닝, 연습 모드, 서킷별 기록과 고스트, 실시간 변수 랭킹·저장, 주변 차 소리(v8). 카테고리 메뉴와 동시 저장 보강(v9). 백업 코드(v11), 벽 접촉 완화(v12). 경사에 따라 기우는 차체와 바퀴별 온도·마모·타이어 점검(v2.6). Q1–Q3, 포메이션 랩, 연료·브레이크 온도·락업·플랫스팟, 트랙 고무·온도, 구역별 비와 드라이 라인, VSC·블루 플래그, 고장, AI 언더컷, 팀별 성격, 7가지 세팅(v3.0). 벽에 끼인 AI 복구(v3.1). 코드 불러오기 뒤 키 오작동 수정(v3.2). 온라인 저장 용량 줄이기(v3.3). 8개 서킷을 실제 지도·지형으로(모양·길이·고저, 실제 건물·숲·물·랜드마크, 먼 산; v4.0). 가까이 지나는 다른 구간 표시·트랙 침범 건물 수정(v4.1). 다리·제방, 실제 지형(HIGH 교차로, ULTRA 전체), 다른 구간을 덮던 잔디 수정(v4.2). 건물이 벽을 덮던 그리기 순서 수정(v4.3). 실제 서킷 6개 추가: 바레인·멜버른·몬트리올·레드불 링·잔드보르트·오스틴(v5.0). 연산 정수화로 tessvm 약 4% 가속(v5.1). 물리·AI 계산 정수화로 tessvm 최대 6% 가속(v5.2). 실제 서킷 5개 추가(이몰라·헝가로링·바르셀로나·제다·라스베이거스, 19곳), 피트 휠건 미니게임, 사진 모드, 그래픽 AUTO(v6.0). 로딩 화면과 그리기 계산 정수화·전처리로 느린 PC에서 7~10% 가속(v6.1). 헤어핀 잔디 띠가 도로를 덮던 버그와 건물·도로·땅 그리기 순서 수정(v6.2). AI 사고·고장이 너무 잦던 버그(엔트리 무작위 수 반올림), 헤어핀 도로 이탈 오판정, 내리막 점프, 앞차·옆 차를 보는 AI(v6.3). 이름을 F1 Online 3D로 바꾸고 온라인 저장·랭킹을 Entry Sync 확장의 `?!` 리스트로(2.0.0). 온라인 대전(방 만들기·입장), 관전, 채팅(2.1.0). 올리기 크기 초과 수정(2.1.1). 온라인 끊김·작품 정지 처리와 복귀(2.1.2). 개인·세계 최고기록이 안 바뀌던 버그(2.1.3). 온라인 방 차 규칙: 업그레이드 켜기, 모두 같은 차(2.2.0). 오늘의 도전: 날마다 바뀌는 서킷·차·조건과 그날의 랭킹, 연속 보상(2.3.0). 온라인 빠른 채팅, 숫자 키 3~9(2.4.0). 커리어 모드: 8개 팀, 6라운드 시즌, 팀 목표·라이벌·평판·계약(3.0.0). 후진 조향이 좌우 바뀌던 버그(3.0.1). 경주 전체 리플레이와 자동 하이라이트(3.1.0). 손상 확장: 서스펜션·펑크·엔진(3.2.0). 세이프티카 로드카 모델(3.3.0). 처음이라면 `3D 레이싱 소개.md`(사용법과 사용된 기술), 최신 변경은 `F1 Online 3D v3.3.0 설명서.md`, 썸네일은 `3D 레이싱 썸네일.png`(이전 설명서는 `old/`)
