## 엔진에서 알아 둘 것
- **그리기**: 방 = 볼록 상자라 면 정렬 없음. 깊이별 스택(`DPH` 0 벽 / 1 포털 하나씩 / 2 물체·레이저 후 pop). 창은 화면 다각형(반시계, `CLX`, 변 상수 `CUX/CUY/CC`, 상자 `WX0..`)으로 다음 깊이를 자른다. 출구 면은 옮긴 카메라 뒤라 뒷면으로 빠진다.
- 서 있는 문틀·상자 문(PFR=1)은 방 가운데 창이라: 그 면 뒤의 물체(페이즈 0) → 창 → 나머지 물체.
- 붓 선은 그 오브젝트의 채우기 아래 층이라 쓸 수 없다. 선 = 얇은 채우기(`lineW`, 창에 Cyrus-Beck). 테두리 = 창보다 큰 사각형 하나(창 아래).
- **통과**: 눈이 면 앞 THR(6 cm·크기)을 넘을 때. 나온 뒤 눈을 출구 앞 2 THR로 민다(되돌아 통과 방지). 몸이 문 크기에 맞을 때만 벽·바닥·천장에 구멍(`holeFit`, 반지름 0.95배). 문틀·구멍 안에서 옆으로 가면 그 안에 묶어 둔다(안 그러면 바닥 위로 튀어 올랐다).
- 값 함수 안에 반복을 두지 않는다(순정에서 비동기로 떨어짐): `holeFit`, `crossing`, `busy`는 결과를 전역(`hfit`, `crossP`, `busyV`)에 둔다.
- `&&`는 단락하지 않는다: `while (i > 1 && ZK[i-1] < key)`가 `ZK[0]`을 읽어 멈췄다.
- 벽 위 포털과 레이저: 벽까지의 t와 포털까지의 t가 같아 `t < tb`에서 빠졌다 → `t < tb + 0.0001`.
- 들고 있는 큐브는 앞의 고체까지 당겨 둔다(안 그러면 벽 너머 틈 안에 넣을 수 있었다).
- 바닥 구멍 위에 내려놓은 큐브는 구멍 가운데로 미끄러진다(깔때기).

## 속도 (헤드리스 순정 / tessvm Node)
- 순정은 창 너머 면 자르기가 비용 대부분(면 하나에 블록 평가 800~2000). 상수 풀 끄기(`PLAINNUM`) 16 → 22 fps, 0 초기화 빼기 22 → 23 fps, 화질 1(깊이 2, 2500 px² 미만 창은 어둠) 기본.
  - 2스테이지 28 fps, 6: 34, 15: 38, 20: 54, 11·24: 11, 22: 9, 18(토러스): 5.
- tessvm 화질 3(깊이 4, 600 px²) 기본: 18스테이지 6.9 ms/틱(가장 무거움), 11·24 1.6, 2 1.0.
- 토러스 방은 처음엔 벽 전체 문(4×3)에 받침대가 있어 tessvm 깊이 5에서 611면 14.7 ms → 문 2.4×2.6, 받침대 없앰.
