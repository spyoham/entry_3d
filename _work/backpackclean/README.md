# 엔트리 보관함 초기화 (크롬 확장)

로그인한 계정으로 **만들기 화면**(`https://playentry.org/ws/...`)이나 **자기 마이페이지**
(`https://playentry.org/profile/<내 id>`)에 가면 오른쪽 아래에 패널이 뜬다.

1. **내 보관함 세기**: 보관함 항목을 받아 오브젝트·블록 수를 보여 준다 (지우지 않음).
2. "되돌릴 수 없다는 것을 압니다"에 체크한 뒤 **N개 모두 삭제**를 누른다.
3. 다 지운 뒤 실패한 것이 있으면 목록을 다시 받아 남은 것을 다시 지운다 (최대 3바퀴).
   처음 셀 때 없던 항목(그 사이 새로 넣은 것)은 건드리지 않는다. **멈추기**로 언제든 멈출 수 있다.
4. 만들기 화면에서 보관함이 열려 있었으면 끝난 뒤 사이트가 목록을 다시 그린다.

## 설치

`chrome://extensions` → 개발자 모드 켜기 → **압축해제된 확장 프로그램을 로드합니다** → 이 폴더(`_work/backpackclean`).
크롬 111 이상 (콘텐츠 스크립트를 `world: "MAIN"`으로 띄운다).

## 쓰는 API (2026-11 사이트 코드에서 확인)

사이트(`ws/[id]` 페이지의 2629 청크)가 axios로 부르는 REST API를 그대로 쓴다. 쿠키만으로 되고 CSRF 헤더는 없다.

- 목록: `GET /rest/backpack?c=<시각>` → `[{ _id, type: "object" | "block", title, imgPath, … }]`
  (항목 id가 `_id`인 것은 entry-tool의 Backpack `makeItemList`에서 확인).
- 삭제: `DELETE /rest/backpack/<_id>` (보관함 항목의 × 버튼, `removeBackPackItem`과 같은 것). 한 번에 하나, 사이 150 ms.
  404(이미 없음)는 지워진 것으로 친다.
- 로그아웃 상태면 둘 다 `401 {"errors":[{"message":"Unauthorized"}]}`: 패널에 "로그인이 필요합니다"로 나오고 지우기를 멈춘다.
- 서버가 붙잡으면 10 초에 끊고 2·4·6… 초 쉬었다 다시 (5번까지), 429·5xx도 다시.

## 시험

- 로그아웃 상태의 만들기 화면에서 진짜 API로: "세기 실패: 로그인이 필요합니다 (401)".
- 같은 화면에서 `fetch`를 가짜 보관함(오브젝트 4 + 블록 3, 하나는 첫 삭제에 403)으로 바꿔:
  체크 전에는 삭제 요청 0개, 체크 후 7개 삭제 → 403 난 하나를 다시 받아 지움 → "끝났습니다. 7개 삭제", 다시 세면 "이미 비어 있습니다".
- 로그인한 계정의 진짜 보관함으로는 지워 보지 않았다.
