# tessvm 실시간 변수 보정 (임시 확장)

tessvm 0.3.x에서 엔트리 **실시간 변수**가 저장되지 않는 문제를, tessvm 제작자가 고칠 때까지 임시로 바로잡는 크롬 확장이다.
원인 분석은 `../tessvm/tessvm-실시간변수-버그.md`.

## 하는 일
`ext/hook.js`가 playentry.org 페이지(`/ws` 편집기 제외)의 `WebSocket`을 감싸고, socket.io 소켓(`EIO=`)의 **변수 set 메시지만** 고친다.

| 방향 | tessvm 0.3.9 | 보정 뒤 |
|---|---|---|
| 보낼 때 | `{type:'set', data: 값}` | `{type:'set', value: 값}` (엔트리·서버 형식) |
| 받을 때 | `value`만 옴 → tessvm이 `data`를 읽어 `undefined` | `data`에도 같은 값을 복사 |

- 리스트 작업(insert/delete/replace)은 원래 `data`를 쓰므로 건드리지 않는다.
- 이미 `value`로 보내는 메시지(엔트리 기본 실행기, 고쳐진 tessvm)는 그대로 둔다. tessvm이 고쳐진 뒤 남아 있어도 해가 없다.
- 새 요청을 만들지 않는다. 페이지가 보내는 메시지의 형식만 바꾼다. 권한 요청 없음.

## 고치지 못하는 것 (tessvm 내부 문제)
- **연결 전 쓰기:** 소켓이 열리기 전에 쓴 값은 tessvm이 아예 보내지 않는다. 게임은 불러오기 뒤에 저장하고, 저장 뒤 다시 읽어 확인해야 한다.
- **원격 변경 때 되돌림:** 다른 사람의 값이 오면 tessvm이 아직 안 보낸(1초 주기) 내 쓰기를 저장소 값으로 되돌릴 수 있다. 역시 저장 확인·재시도로 막는다.

## 설치
- 시험: `chrome://extensions` → 개발자 모드 → **압축해제된 확장 프로그램을 로드합니다** → `ext` 폴더.
- 배포: `tessvm-cloudfix-1.0.0.zip`을 크롬 웹 스토어 개발자 대시보드에 올린다.
- 작동 확인: 작품 페이지에서 F12 콘솔에 `[tessvm 보정] socket.io 소켓 보정 중`이 보이고,
  `[CloudClient] Send:`는 **보정 전** 모습(`data`)으로 찍힌다(tessvm이 보내기 직전에 찍으므로). 실제로 나가는 형식은 개발자 도구 Network → WS에서 확인.

## 시험
`node test.mjs` — `_work/tessvm/ext`(tessvm 0.3.9 CRX 풀어둔 것)의 실제 `page/cloud.js`를 가짜 소켓에 붙여 보정 없이/있이 비교한다.
실제 서버 저장은 아직 확인하지 않았다(업로드한 작품과 로그인이 필요).

## tessvm이 고쳐지면
확장을 지우면 된다(남아 있어도 해는 없다). 게임의 `writeOK()` 조건도 함께 정리한다.
