# 엔트리 이야기 1시간 뒤 삭제 (크롬 확장)

로그인한 계정이 쓴 **엔트리 이야기 글**을 쓴 지 1시간이 지나면 자동으로 지운다.
댓글(남의 글에 단 내 댓글)은 건드리지 않는다. 남의 글, 다른 게시판(묻고 답하기·노하우&팁 등) 글도 건드리지 않는다.
지운 글은 되돌릴 수 없다.

## 설치

`chrome://extensions` → 개발자 모드 켜기 → **압축해제된 확장 프로그램을 로드합니다** → 이 폴더(`_work/storyhour`).

깔면 설명 화면이 열린다. **처음에는 꺼져 있다.** "자동 삭제 켜기"를 체크해야 지우기 시작한다.
꺼져 있는 동안에는 "지금 켜면 지워질 글"이 몇 개인지만 세어 보여 준다.
켜는 순간 1시간 넘은 내 글이 (예전 글까지 전부) 지워진다.

나중에는 도구 모음의 확장 아이콘을 누르면 같은 화면이 뜬다 (켜져 있으면 아이콘에 `ON`).

## 어떻게 도나

- 1분마다 한 번 확인한다. 그래서 글은 쓴 지 60~61분쯤에 사라진다.
- 크롬이 켜져 있어야 한다. 엔트리 탭은 닫아 두어도 된다
  (보이는 엔트리 탭이 있으면 그 탭에서, 없으면 확장의 배경에서 직접 요청한다).
- 엔트리에 로그아웃되어 있으면 아무것도 하지 않는다.
- 1시간은 서버 시계(응답의 `Date` 헤더)로 잰다. 컴퓨터 시계가 틀려도 된다.
- 한 번에 20개씩 묶어 지우고, 한 차례에 1분까지만 쓴다. 글이 아주 많으면 다음 차례에 이어서 지운다.
- 시간을 바꾸려면 `core.js` 맨 위의 `MAX_AGE_MS`.

## 쓰는 API (2026-11 사이트 코드에서 확인)

- 목록: `POST /graphql/SELECT_ENTRYSTORY` — `discussList(user: <내 id>, category: "free", …)`, 새 글부터 50개씩,
  `searchAfter`로 다음 쪽. 받은 글마다 `user.id`가 나인지, `category`가 `free`인지, `created`가 1시간 넘었는지 본다.
- 삭제: `POST /graphql/REMOVE_DISCUSS` — `removeDiscuss(id)` (사이트의 글 삭제 버튼과 같은 것), 별칭으로 20개 묶음.
- 헤더: `CSRF-Token`, `x-token`, `x-client-type: Client`, 쿠키 포함. 토큰이 낡아 401이 오면 페이지를 새로 받아 한 번 다시 한다.

글을 모두 한꺼번에 지우는 것은 `_work/storyclean`.

## 시험

`node test.mjs` — 가짜 서버를 상대로 지울 것만 지우는지 본다 (진짜 서버에는 아무것도 안 보낸다).

진짜 크롬에 올려 로그아웃 상태로 확인한 것: 설치·켜기·끄기, 배경과 탭 양쪽에서 로그아웃을 알아보는 것,
배경에서 진짜 서버의 목록을 끝까지 읽는 것(공개 글 642개 중 1시간 넘은 636개를 5초에 셈).
**로그인한 채 실제로 지우는 것은 확인하지 못했다** — 삭제 요청의 모양은 `_work/storyclean`과 같다.
