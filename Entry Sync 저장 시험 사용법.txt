Entry Sync 저장 시험 사용법

작품을 새 판으로 덮어씌워도 블록 월드의 서버(맵) 기록이 남는지 알아보는 시험용 작품입니다
파일 두 개를 씁니다: Entry Sync 저장 시험 v1.ent, Entry Sync 저장 시험 v2.ent


꼭 지킬 것

블록 월드 작품에서 하지 마세요. 반드시 새 작품으로 하세요
이 시험 작품은 블록 월드와 같은 이름의 ?! 리스트(?!m1, ?!m2, ?!e1, ?!gone)를 씁니다
Entry Sync는 작품 번호와 리스트 이름으로 기록을 저장하므로, 블록 월드 작품에 올리면 진짜 서버 목록을 덮어씁니다
같은 이름을 쓰는 까닭은 블록 월드에서 일어날 일과 똑같이 시험하기 위해서입니다

Entry Sync 확장을 켜고 엔트리에 로그인한 상태에서 합니다
화면 맨 위의 "연결: 됨"을 확인하세요. "안 됨"이면 결과를 믿을 수 없습니다


1 처음 기록하기 (판 1)

1. 엔트리 만들기 화면에서 새 작품을 만들고 Entry Sync 저장 시험 v1.ent를 불러온 뒤 저장합니다
   이때 주소창의 작품 번호를 적어 두세요 (예: playentry.org/ws/1234abcd... 의 뒷부분)
2. 작품을 실행합니다. 7초쯤 기다리면 표가 나옵니다
3. 키보드 1을 누릅니다. 표의 다섯 줄이 모두 ○ 남음이 되고 "기록됨"이 나옵니다
   표지 숫자(예: 1886)를 적어 두세요
4. 작품을 정지하고 이 창(탭)을 닫습니다. 10초쯤 기다립니다
   ?! 기록은 마지막 사람이 나가 방이 빌 때 Entry Sync 서버에 저장되므로, 창을 꼭 닫아야 합니다


2 새 판으로 덮어쓰기 (판 2)

시험 가. 그대로 덮어쓰기
1. 같은 작품을 만들기 화면에서 엽니다
2. 블록 월드를 새 판으로 올릴 때와 똑같은 방법으로 Entry Sync 저장 시험 v2.ent로 바꾸고 저장합니다
3. 주소창의 작품 번호가 1에서 적어 둔 것과 같은지 확인합니다. 다르면 새 작품이 된 것이라 이 시험은 맞지 않습니다
4. 만들기 화면을 닫고, 작품 페이지에서 실행합니다(또는 그대로 실행). 7초 기다립니다

시험 나. 함수·리스트·변수를 다 지운 뒤 다시 넣기
1. 판 1로 다시 기록부터 합니다 (1의 순서를 다시: 판 1 파일로 바꾸고 1을 눌러 기록, 정지, 창 닫기)
2. 만들기 화면에서 함수, 리스트, 변수를 모두 지우고 저장합니다
3. 이어서 v2 파일로 바꾸고 저장합니다 (작품 번호가 같은지 확인)
4. 실행하고 7초 기다립니다

시험 다. 만들기 화면에서 조금만 고치기 (선택)
판 2인 채로 만들기 화면을 열어 블록 하나를 옮기거나 변수 하나를 새로 만들었다 지운 뒤 저장하고 실행해 봅니다


3 결과 읽기 (판 2 화면)

맨 위에 "판 2"인지, "연결: 됨"인지 먼저 봅니다

?!m1 서버 목록, ?!e1 블록 기록, ?!시험값 변수, ?!gone 지운 서버 목록
  블록 월드의 서버 목록과 블록 기록이 저장되는 것과 같은 종류(?!)입니다
  ○ 남음이면 덮어써도 남은 것, ✕ 사라짐이면 지워진 것입니다
  표지 숫자가 1에서 적어 둔 것과 같아야 합니다
??시험값
  ??는 작품을 정지할 때 저장되는 다른 종류입니다. 비교용입니다
?!m2
  판 2 파일에는 이 리스트의 시작값이 따로 들어 있습니다
  "판 1이 서버에 쓴 값"이 보이면 서버에 남은 기록이 이긴 것이고
  "판 2 파일에 들어 있던 시작값"이 보이면 새 파일의 값이 서버 기록을 덮어쓴 것입니다

맨 아래 결론
  새 판으로 덮어써도 서버(맵) 기록이 남습니다 - 블록 월드도 새 판을 올려도 서버가 남습니다
  새 판으로 덮어쓰니 서버(맵) 기록이 사라졌습니다 - 블록 월드도 새 판을 올리면 서버 목록이 비워집니다
    이때는 서버에 들어가 본 사람이 tessvm으로 멀티플레이 화면을 열면, 그 사람 컴퓨터에 보관된 사본(v2.3부터)으로 서버가 되살아납니다
  일부만 남았습니다 - 어느 줄이 사라졌는지 표를 보세요

다른 시험을 하기 전에는 0을 눌러 모두 비우고 다시 1부터 하면 됩니다


결과를 알려 주시면
시험 가, 나, 다 각각의 결론과 ?!m2 줄을 알려 주세요. 블록 월드를 새 판으로 올리는 안전한 방법을 거기에 맞춰 정하겠습니다
