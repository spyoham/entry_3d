# 3D 레이싱 v5.0 — 설명서

`3D 레이싱 v5.0.ent`는 **실제 F1 서킷 6곳을 더해 모두 14곳**이 된 큰 업데이트입니다. 새 서킷도 v4의 8곳과 같은 방식(실제 지도·지형 자료)으로 만들어서, 모양·길이·고저와 주변 건물·숲·물·관중석·먼 산이 실제와 같습니다. 서킷 안내는 `3D 레이싱 소개.md` 14장, 조작은 `3D 레이싱 사용법과 게임 소개.md`를 보세요.

- 길이는 실제보다 0.5% 안팎 짧습니다(중심선을 매끈하게 다듬은 만큼).
- 고저차: 레드불 링 65 m, 오스틴 41 m는 공식 값에 맞췄고, 나머지는 위성 지형 자료 그대로입니다.
- 주변: 지도에 있는 건물(바레인·잔드보르트 관중석과 건물, 멜버른 도심), 숲(레드불 링, 몬트리올), 물(앨버트 파크 호수, 몬트리올 강과 조정 경기장)을 실제 자리에 놓았습니다.
- ULTRA에서는 새 서킷도 주변 실제 지형(언덕·비탈)을 그립니다.

## 함께 바뀐 것
- **챔피언십**은 14라운드입니다.
- **서킷 기록**: 새 서킷의 최고 랩·레이스 기록, 온라인 랭킹, 세계 기록 고스트가 따로 있습니다. 예전 기록과 백업 코드는 그대로 이어집니다(새 서킷 기록은 저장 레코드 뒤쪽에 붙습니다).
- **프로필 > 기록** 화면은 14개 서킷을 두 줄(7개씩)로 보여 줍니다.
- 도전과제 "모든 서킷 완주"는 14곳을 모두 달려야 합니다.

## 확인한 것
- 새 6개 서킷: 풍경이 도로·런오프에 걸친 곳 0, AI가 1 m 넘게 코스를 벗어난 일 0(240초), AI 랩 103–158초(고스트 저장 한도 216초 안).
- tessvm: 멜버른 HIGH 59–60 fps, 멜버른·몬트리올 ULTRA 59–60 fps.
- v3.0 기능 검사 10개, 키, 동시접속, 백업 코드 31개, 텍스트 칸, 차체 기울기(14개 서킷), 벽에 끼인 차, 리스트 채우기 테스트 통과.
