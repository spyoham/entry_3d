# 3D 레이싱 v5 (F1 에디션) — 설명서

`3D 레이싱 v5.ent` 는 v4의 F1 서킷 8개 위에 **F1 머신, 게임 모드, 날씨, 레이스 규칙**을 올린 버전입니다.
v1–v4 파일은 그대로 남아 있습니다.

## v4에서 달라진 것

| | v4 | v5 |
|---|---|---|
| 차 | 상자형 GT (면 30개) | **F1 오픈휠** (노즈·앞뒤 윙·사이드포드·헤일로·헬멧·조향되는 앞바퀴, 면 95개), 해의 방향에 따라 실시간 명암 |
| 모드 | 레이스 1가지 | **그랑프리 / 챔피언십(8라운드) / 타임 트라이얼(고스트)** |
| 출발 | 3-2-1 | **F1 스타트 라이트 5개** (다 켜진 뒤 불규칙한 시간 후 꺼지면 출발) |
| 레이스 규칙 | — | **슬립스트림, DRS**, 섹터 기록, 라이브 델타, 결과표, 챔피언십 포인트 |
| 날씨 | 맑음 | **맑음 / 비** (접지력 −20%, 빗줄기·물보라·짙은 안개) |
| 그래픽 | 고정 | **LOW / HIGH / ULTRA** |
| 랩 수 | 3 고정 | **1 / 3 / 5 / 10** |
| 카메라 | 3종 | 4종 (**T캠** 추가) |
| HUD | 속도·랩·순위 | + 기어, 레브 LED, DRS, 타이밍 타워, 섹터/델타 |
| 보조 | — | **레이싱 라인** (L 키) |

## 메인 메뉴 (↑↓ 선택, ←→ 변경, ENTER 확정)

1. **시작** — 모드에 따라 RACE START / START CHAMPIONSHIP / START TIME TRIAL
2. **MODE** — GRAND PRIX(한 경기), CHAMPIONSHIP(8개 서킷 연속), TIME TRIAL(혼자 기록 도전)
3. **CAR** — 4대 (ENTER로 차고 화면)
   - ROSSO R5: 균형형 · ARGENTO W: 최고속 346 km/h, 코너 약함 · AZURE RB: 다운포스, 코너 강함 · ARANCIA MC: 가속 좋음
4. **TRACK** — 서킷 8개 + 에디터로 만든 서킷 (챔피언십에서는 자동)
5. **AI LEVEL** — ROOKIE ~ INSANE
6. **LAPS** — 1 / 3 / 5 / 10
7. **WEATHER** — DRY / RAIN
8. **GRAPHICS** — LOW / HIGH / ULTRA (아래 참고)
9. **TRACK EDITOR** — v4와 같음

## 레이스 규칙

- **스타트**: 빨간 불 5개가 1초 간격으로 켜지고, 잠시 뒤 **모두 꺼지는 순간** 출발입니다. 플레이어는 6번째 그리드에서 출발합니다.
- **슬립스트림**: 앞차 바로 뒤(40 m 이내)를 따라가면 공기저항이 줄어 더 빨라집니다.
- **DRS**: 서킷에서 가장 긴 직선 2곳이 DRS 존입니다. 2랩째부터, 존에 들어갈 때 **앞차와 1초 이내**면
  화면 왼쪽 아래에 주황색 **DRS E**가 뜹니다. **E**를 누르면 리어윙이 열려(녹색 **DRS OPEN**) 최고속이 올라갑니다.
  브레이크를 밟거나 존이 끝나면 닫힙니다. 타임 트라이얼에서는 항상 쓸 수 있습니다. AI도 씁니다.
- **섹터**: 한 바퀴를 3구간으로 나눠 기록합니다. 보라색 = 개인 최고, 노란색 = 느림.
  그 밖의 시간에는 최고 랩 대비 **DELTA**(녹색 = 더 빠름, 빨강 = 더 느림)가 나옵니다.
- **트랙 리밋**: 네 바퀴가 모두 흰 선 밖으로 0.6초 넘게 나가면 그 랩 기록은 삭제됩니다(v4와 같음).
- **결과**: 내가 들어오면 결과표가 나오고, 다른 차들은 계속 달려 결승선을 통과합니다.
- **챔피언십**: 1–8위에 25-18-15-12-10-8-6-4점. 경기마다 ENTER → 순위표 → ENTER → 다음 서킷. 8라운드 후 챔피언 발표.
- **타임 트라이얼**: 혼자 무제한으로 달립니다. 최고 랩이 나오면 다음 랩부터 **하늘색 고스트 차**가 그 랩을 그대로 달립니다.
  같은 서킷에서 R로 재시작해도 고스트와 기록이 남습니다.

## 레이싱 라인 (L)

도로 위에 이상적인 주행 라인이 띠로 표시됩니다. 색은 **지금 내 속도** 기준입니다.
- 녹색: 계속 가속해도 됨 · 주황: 액셀을 떼세요 · 빨강: 지금 속도로는 못 도니 브레이크

## 비 (RAIN)

접지력이 약 20% 줄고 제동 거리가 늘어납니다. 시야가 짧고, 앞차의 물보라가 보입니다. 브레이크를 일찍 밟으세요.
AI도 비에 맞춰 속도를 줄입니다.

## 그래픽 옵션과 성능

| | 가까운 풀 모델 차 | 도로 상세 거리 | 풍경 거리 | 기타 |
|---|---|---|---|---|
| LOW | 1대 | 62 m | 270 m | v4 수준, 흰 선 없음 |
| HIGH (기본) | 4대 | 110 m | 420 m | 흰 가장자리 선, 안개 +15% |
| ULTRA | 8대 | 170 m | 600 m | 풍경 밀도 2배, 안개 +35% |

- 이 버전은 **계산 가속 확장 프로그램 사용을 전제**로 HIGH가 기본입니다.
  확장 없이 순정 엔트리에서 돌리면 1–3 fps 정도라 **LOW**를 권장합니다.
- 확장을 쓰면 계산보다 **그리는 폴리곤 수**가 속도를 좌우합니다. 끊기면 LOW/HIGH로 낮추세요.
- 모든 리스트는 5000칸 이하입니다 (가장 큰 것: 정점 버퍼 4938칸).
