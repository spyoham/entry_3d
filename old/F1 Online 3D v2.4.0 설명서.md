# F1 Online 3D v2.4.0 — 설명서

`F1 Online 3D v2.4.0.ent`는 온라인에 **빠른 채팅**을 더한 판입니다. 나머지는 v2.3.0과 같습니다. 이전 내용은 `old/` 폴더의 설명서를 보세요(오늘의 도전은 `old/F1 Online 3D v2.3.0 설명서.md`).

## 1. 빠른 채팅
온라인에서 숫자 키 하나로 짧은 말을 보냅니다. 달리면서 Y를 눌러 글을 칠 필요가 없습니다.

| 키 | 말 |
|---|---|
| 3 | GOOD LUCK! |
| 4 | NICE PASS! |
| 5 | SORRY! |
| 6 | THANKS! |
| 7 | GG |
| 8 | WATCH OUT! |
| 9 | LET'S GO! |

- 로비, 방, 경주 중, 결과 화면, 관전 중 어디서나 됩니다. 받는 사람은 Y 채팅과 같습니다(로비는 로비, 방은 그 방과 관전자).
- 경주 중에는 화면 가운데 위 채팅 줄에 14초 동안 보입니다. 게임은 멈추지 않습니다.
- 도배를 막으려고 빠른 채팅은 1초에 한 번만 보냅니다.
- 1과 2는 리얼리스틱의 브레이크 밸런스 키라서 쓰지 않았습니다.
- 숫자 키는 온라인에 있을 때만 읽습니다. 오프라인에서는 아무 일도 하지 않고, 오프라인 게임의 속도에도 영향이 없습니다.

## 2. 어디에 안내가 나오나
- **방 화면**: 규칙 아래에 키 목록 두 줄.
- **출발선**(신호등을 기다리는 동안): 화면 아래쪽에 키 목록 두 줄. 출발하면 사라집니다.
- **경주 중**: 오른쪽 아래 `Y CHAT   3-9 QUICK`.

## 3. 시험한 것
- `t9/netsim.mjs quick`(새로 만듦, Entry Sync 모델, 세 사람). 키는 실제로 누르는 것처럼 넣었습니다.
  - 오프라인에서 3은 아무 일도 안 함.
  - 방에서 3이 방 사람에게만 가는지, 방 화면 목록.
  - 1초 안에 두 번 누르면 두 번째는 안 감.
  - 출발선 목록이 출발 뒤 사라지는지, 경주 중 9.
  - 리얼리스틱에서 2는 여전히 브레이크 밸런스인지, 관전자의 빠른 채팅.
  - 결과: 9개 모두 PASS.
- `t9/nettess.mjs`(tessvm 두 창 + 실제 Entry Sync 스크립트): 방에서 bob이 키 4를 누르면 alice에게 "NICE PASS!"가 가는 단계를 더했습니다. 15개 모두 PASS. 방 화면 스크린숏 `_work/racing/ab/net_room.png`.
- 회귀: `t9/netsim.mjs` 전체, `t9/daily.mjs`, `t9/tests.sh`, `t9/rec.mjs`, `t7/prof.mjs` → `_work/racing/ab/*240.txt`.
