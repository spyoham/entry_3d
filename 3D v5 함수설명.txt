==========================================================================
3D 엔진 v5  -  함수 설명서
==========================================================================

엔트리에서 3D v5.ent 를 열면 함수 목록에 아래 블록들이 그대로 들어 있습니다.
( ) 는 값을 넣는 칸입니다.
블록 이름 앞에는 종류를 알려 주는 작은 그림이 붙어 있지만, 이 문서에서는
빼고 적었습니다. 이름과 칸 순서는 블록과 똑같습니다.

자세한 사용법과 예제는 "3D v5 사용설명서.md" 를 보세요.


--------------------------------------------------------------------------
1. 엔진 기본
--------------------------------------------------------------------------

3D 엔진 시작하기
    프로그램을 시작할 때 딱 한 번 부릅니다.
    시계, 카메라, 빛, 붓, 내부 목록을 모두 처음 상태로 맞춥니다.

3D 월드 비우기
    만들어 둔 오브젝트를 전부 지우고 빈 월드로 되돌립니다.
    게임을 다시 시작하거나 다른 장면으로 바꿀 때 씁니다.

프레임 시작하기
    한 프레임의 맨 앞에서 부릅니다.
    프레임시간(dt) 계산, 키보드 읽기, 트윈과 타이머 갱신을 합니다.

3D 장면 그리기
    지금 월드를 화면에 그립니다. 보통 한 프레임의 맨 끝에 부릅니다.
    붓을 쓰므로 그림을 그릴 오브젝트(게임 오브젝트)에서 불러야 합니다.

3. 내 모양 디자인하기
--------------------------------------------------------------------------

새 모양 만들기 시작
    내 모양 만들기를 시작합니다. 이 다음에 점과 면을 추가합니다.

모양에 점 추가  x ( )  y ( )  z ( )
    모양에 점을 하나 찍습니다. 찍은 순서대로 1번, 2번, 3번 ... 이 됩니다.
    좌표는 -0.5 에서 0.5 사이로 잡으면 크기 조절이 편합니다.

모양에 면 추가  점 ( ) ( ) ( ) ( )  색 ( )
    점 번호 네 개로 면을 하나 만듭니다. 네 번째를 0으로 하면 삼각형입니다.
    점 순서를 거꾸로 적어도 됩니다. 내가 만든 면은 양쪽에서 다 보입니다.
    색을 비우면 오브젝트 색을 따릅니다.

모양 완성하기
    모양 만들기를 끝냅니다. 만들어진 모양 번호가 변수 만든모양 에 들어옵니다.

모양 ( ) 의 먼 거리 모양을 ( ) 번으로 정하기
    어떤 모양이 화면에서 작아지거나 멀어지면 대신 그릴 간단한 모양을 정합니다.
    면 수를 줄여서 빨라집니다.

4. 오브젝트 다루기
--------------------------------------------------------------------------

오브젝트 ( ) 위치를  x ( )  y ( )  z ( )  로 정하기
    오브젝트를 그 자리로 순간이동시킵니다.

오브젝트 ( ) 을  x ( )  y ( )  z ( )  만큼 움직이기
    오브젝트를 지금 위치에서 그만큼 움직입니다.

오브젝트 ( ) 을  x ( )  y ( )  z ( )  만큼 돌리기
    오브젝트를 지금 각도에서 그만큼 더 돌립니다.
    프레임시간을 곱하면 속도가 일정해집니다.

오브젝트 ( ) 크기를  x ( )  y ( )  z ( )  로 정하기
    오브젝트의 가로 높이 세로 크기를 바꿉니다. 충돌 크기도 같이 바뀝니다.

오브젝트 ( ) 색을 ( ) 로 정하기
    오브젝트 색을 바꿉니다. 색 이름이나 우물정자로 시작하는 색코드를 씁니다.

오브젝트 ( ) 보이기(1)/숨기기(0) ( )
    1이면 보이게, 0이면 안 보이게 합니다. 안 보이는 물체는 그리지 않아 빨라집니다.

오브젝트 ( ) 이름표를 ( ) 로 정하기
    오브젝트에 이름표를 붙입니다. 적, 별, 벽 처럼 무리를 지을 때 씁니다.
    이름표로 닿았는지 검사하기와 함께 쓰면 편합니다.

오브젝트 ( ) 그림자 ( )
    이 오브젝트의 그림자를 켜거나 끕니다. 1 켜기, 0 끄기.

오브젝트 ( ) 항상 카메라 보기 ( )
    1로 하면 어느 쪽에서 봐도 항상 카메라를 향합니다. 간판, 풀, 이펙트에 씁니다.

오브젝트 ( ) 빛 무시하기 ( )
    1로 하면 빛 계산을 하지 않고 항상 같은 밝기로 보입니다. 아이템에 좋습니다.

오브젝트 ( ) 그리기 층을 ( ) 로 정하기 (-1 바닥 0 보통 1 맨앞)
    그리는 순서를 정합니다. -1은 항상 뒤(바닥용), 0은 보통, 1은 항상 앞입니다.

오브젝트 ( ) 의 충돌 크기를  가로 ( )  높이 ( )  세로 ( )  로 정하기
    모양에서 자동으로 잡힌 충돌 상자 크기를 직접 바꿉니다.
    먹기 쉬운 아이템은 충돌 크기를 조금 크게 잡으면 좋습니다.

오브젝트 ( ) 을 바라보는 쪽으로 ( ) 만큼 가기
    오브젝트가 바라보는 방향(회전Y)으로 그만큼 앞으로 갑니다.

오브젝트 ( ) 이  x ( )  y ( )  z ( )  를 바라보게 하기
    오브젝트가 그 지점을 바라보도록 회전Y를 맞춥니다.

오브젝트 ( ) 을 바닥 높이 ( ) 에 세우기
    오브젝트를 그 높이의 바닥에 딱 세웁니다. 높이 계산을 대신 해 줍니다.

5. 부드러운 움직임과 붙이기
--------------------------------------------------------------------------

오브젝트 ( ) 을 ( ) 초 동안  x ( )  y ( )  z ( )  로 옮기기  부드럽게 ( )
    정해진 시간 동안 부드럽게 그 위치까지 움직입니다.
    부드럽게: 0 일정한 속도, 1 부드럽게, 2 천천히 시작, 3 천천히 끝.
    프레임 시작하기가 알아서 굴려 줍니다. 문, 엘리베이터, 연출에 씁니다.

오브젝트 ( ) 을 ( ) 초 동안  회전 x ( )  y ( )  z ( )  로 돌리기  부드럽게 ( )
    정해진 시간 동안 부드럽게 그 각도까지 돌립니다.

오브젝트 ( ) 을 ( ) 초 동안  크기 ( ) ( ) ( )  로 바꾸기  부드럽게 ( )
    정해진 시간 동안 부드럽게 그 크기까지 커지거나 작아집니다.

오브젝트 ( ) 의 움직임 멈추기
    그 오브젝트에 걸린 부드러운 움직임을 멈춥니다.

오브젝트 ( ) 을 오브젝트 ( ) 에 붙이기  x ( )  y ( )  z ( )  회전 ( )
    오브젝트를 다른 오브젝트에 붙입니다. 부모가 움직이고 돌면 같이 따라갑니다.
    x y z 는 부모 기준 위치, 회전은 부모 기준 방향입니다.
    모자, 손에 든 무기, 자동차 지붕, 포탑에 씁니다.

오브젝트 ( ) 을 떼어내기
    붙여 둔 오브젝트를 떼어냅니다.

타이머 ( ) 번을 ( ) 초로 맞추기
    타이머 한 칸을 그 초로 맞춥니다. 리스트 타이머 의 값이 매 프레임 줄어듭니다.
    0이 되면 끝난 것입니다. 발사 간격, 제한시간, 무적시간에 씁니다.

6. 물리
--------------------------------------------------------------------------

중력을 ( ) 로 정하기
    중력의 세기를 정합니다. 기본값은 22 입니다. 작게 하면 달나라처럼 됩니다.

오브젝트 ( ) 의 물리를 ( ) 로 정하기 (0없음 1움직임 2고정 3센서 4발판)
    오브젝트의 물리 종류를 정합니다.
    0 없음(장식), 1 움직임(중력과 충돌), 2 고정(땅 벽 건물),
    3 센서(통과하지만 닿은 것은 알려 줌), 4 움직이는 발판(위에 탄 것이 같이 감).

오브젝트 ( ) 의 튕김 ( )  마찰 ( ) 로 정하기
    튕김(0이면 안 튀고 1에 가까우면 잘 튐)과 마찰을 정합니다.

오브젝트 ( ) 의 무게를 ( ) 로 정하기
    무게를 정합니다. 무거운 쪽이 가벼운 쪽을 더 많이 밀어냅니다.

오브젝트 ( ) 을 공 충돌로 ( ) (1켜기 0끄기)
    충돌 모양을 공으로 바꿉니다. 1 켜기, 0 끄기(상자로 되돌리기).

오브젝트 ( ) 을 캡슐 충돌로 ( ) (1켜기 0끄기)
    충돌 모양을 캡슐로 바꿉니다. 사람 캐릭터가 모서리에 덜 걸립니다.

오브젝트 ( ) 의 속도를  x ( )  y ( )  z ( )  로 정하기
    속도를 그 값으로 바로 정합니다.

오브젝트 ( ) 에 힘  x ( )  y ( )  z ( )  주기
    힘을 줍니다. 무게가 무거울수록 덜 밀립니다. 폭발, 밀치기에 씁니다.

오브젝트 ( ) 을 ( ) 높이로 점프시키기
    땅에 닿아 있을 때만 그 높이만큼 점프합니다.

물리 계산하기
    물리를 한 프레임 계산합니다. 안에서 여러 번 잘게 나눠 계산합니다.
    이 블록을 부른 다음에 충돌 결과(닿은것, 땅닿음)를 확인하면 됩니다.

자동으로 올라갈 턱 높이를 ( ) 로 정하기
    걷다가 낮은 턱을 만나면 자동으로 올라갈 높이를 정합니다. 기본 0.45.

미끄러지기 시작하는 경사를 ( ) 도로 정하기
    이 각도보다 가파른 경사면에서는 미끄러져 내려옵니다. 기본 48도.

세상 경계를 크기 ( )  높이 ( ) 로 정하기
    보이지 않는 벽으로 세상의 크기를 정합니다. 밖으로 못 나갑니다.

오브젝트 ( ) 과 ( ) 가 닿았는지 검사하기
    두 오브젝트가 지금 닿았는지 검사합니다. 결과는 변수 닿음 에 1 또는 0.

오브젝트 ( ) 이 이름표 ( ) 와 닿았는지 검사하기

    결과는 변수 닿음, 상대 번호는 변수 닿은상대 에 들어옵니다.
    아이템 먹기, 적과 부딪히기에 가장 편한 방법입니다.

점 ( ) ( ) ( ) 이 상자 ( ) ( ) ( )  크기 ( ) ( ) ( ) 안에 있는지 검사하기

    골인 지점, 위험 구역, 방 안인지 판단할 때 씁니다.

오브젝트 ( ) 이 점 ( ) ( ) ( ) 에서 ( ) 안에 있는지 검사하기

    보이지 않는 광선을 쏘아 무엇에 맞는지 알아봅니다.
    결과는 광선맞음, 광선오브젝트, 광선거리, 광선X, 광선Y, 광선Z 에 들어옵니다.

    메뉴 화면, 쿼터뷰, 자동차 뒤따라가기에 씁니다.

카메라를 ( ) ( ) ( ) 으로 옮기며 ( ) ( ) ( ) 바라보기  시간 ( ) 초

    1로 하면 충돌 상자와 좌표축을 빨간 선으로 보여 줍니다. 만들 때만 켜세요.
