# 엔트리 작품 일괄 비공개 (크롬 확장 프로그램)

playentry.org 마이페이지에서 고른 작품을 한꺼번에 비공개로 바꿉니다.

## 설치
1. 크롬 주소창에 `chrome://extensions` 를 엽니다.
2. 오른쪽 위 **개발자 모드**를 켭니다.
3. **압축해제된 확장 프로그램을 로드합니다**를 눌러 이 폴더(`엔트리 작품 일괄 비공개`)를 고릅니다.

## 쓰는 법
1. playentry.org 에 로그인합니다.
2. 마이페이지의 **작품** 탭(`playentry.org/profile/<내 id>/project`)으로 갑니다.
3. 작품 카드 왼쪽 위에 체크박스가 생기고, 화면 아래에 도구 막대가 뜹니다.
   - 체크박스를 눌러 고릅니다. **Shift+클릭**하면 앞에 누른 것부터 범위로 고릅니다.
   - **보이는 작품 모두 선택** / **선택 해제**
4. **선택한 작품 비공개**를 누르고 확인하면 하나씩 처리합니다.
   카드 오른쪽 위에 `비공개됨` / `이미 비공개` / `실패: …` 가 표시됩니다.

다른 사람의 프로필에서는 나타나지 않습니다.

## 동작
- 엔트리 사이트가 쓰는 GraphQL(`/graphql`)을 로그인한 브라우저의 쿠키로 그대로 부릅니다. 다른 서버로는 아무것도 보내지 않습니다.
- 엔트리의 공개 설정 요청(`toggleIsopenProject`)은 공개 ↔ 비공개를 **뒤집는** 요청입니다.
  그래서 작품마다 먼저 지금 상태를 읽고, **공개일 때만** 한 번 보낸 다음 다시 읽어 비공개가 됐는지 확인합니다.
  이미 비공개인 작품은 건드리지 않습니다.
- 내 작품이 아니면 보내지 않습니다.
- 요청 사이에 0.25초씩 쉽니다.
